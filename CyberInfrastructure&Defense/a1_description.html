Tasks for Section 1

Task 1: Cybersecurity Incident Analysis

Step 1: Select Two Recent Cybersecurity Incidents

Choose two high-impact cybersecurity incidents from the past 3–5 years. Use reliable sources such as:

  • MITRE ATT&CK Incident Database (https://attack.mitre.org)
  • Cybersecurity news sites (e.g., Krebs on Security, BleepingComputer, The Hacker News).
  • Reports from security firms (e.g., Mandiant, CrowdStrike, Palo Alto Networks).
  • Government agencies (e.g., CISA, NIST, ENISA).
Criteria for Selecting Incidents:
  • Recency: Select incidents from the last 3–5 years to ensure relevance.
  • Impact: Choose incidents that affected a major organization, government, or critical infrastructure.
  • Technical Complexity: Look for incidents involving APT groups, sophisticated malware, or supply chain attacks.
  • Available Data: Ensure there is enough information on attack methods and responses.

Step 2: Analyze Each Incident

For each selected incident, provide the following details:

  1. Attack Overview:

    • What happened? Describe the breach, its target, and its impact.
    • Who was affected? (e.g., companies, industries, or government entities).

  2. Key Technical Methods Used (Three Techniques):

    • Identify three key attack techniques used (e.g., malware, spear phishing, privilege escalation).
    • Provide a brief explanation of how each method was used in the attack.

  3. Threat Actor Type:

    • Classify the type of attacker (e.g., nation-state, cybercriminal, insider).
    • If known, identify the specific APT group or threat actor responsible.

  4. Violated Security Goals:

    • Determine which part of the CIA Triad was compromised:
      • Confidentiality (e.g., data theft).
      • Integrity (e.g., data manipulation).
      • Availability (e.g., ransomware causing system downtime).
    • Justify how the attack violated these security goals.

  5. Proposed Defensive Measures:

    • Identify three security controls that could have prevented or mitigated the attack.
    • Relate defenses to the CIA Triad (e.g., encryption for confidentiality, backups for availability).

Task 2: Understanding APTs and MITRE ATT&CK

Step 1. Explore MITRE ATT&CK Enterprise Matrix

Identify two different tactics from MITRE ATT&CK Enterprise Matrix. For each tactic:

  • Mention the ID and name of the selected tactic, and explain its purpose in an APT attack.
  • Provide a real-world example of how it has been used by adversaries.

Step 2. Identify Two Techniques for Each Tactic

For each of the two selected tactics in Step 1, choose two techniques from the same Enterprise Matrix. This results in a total of six techniques. For each selected technique, provide the following details based on MITRE ATT&CK data:

  • 1. Technique Identification & Scope

    • Technique Name & ID: (e.g., Boot or Logon Autostart Execution - T1547)
    • Affected Platforms: (e.g., Windows, Linux, macOS, Network)
    • Required Permissions: (e.g., Administrator, root, user)
    • Tactics Associated: List the primary tactic(s) this technique is associated with.

  • 2. Technique Overview

    • Description: Explain how adversaries use this technique in attacks.
    • Sub-techniques: Identify up to three relevant sub-techniques, if applicable.
    • Adversary Goals: Describe what attackers aim to achieve when using this technique (e.g., persistence, privilege escalation, lateral movement).

  • 3. Real-World APT Usage

    • APT Groups (at least 2): Identify adversaries that have used this technique.
    • Attack Campaigns: Provide details on real-world cyber campaigns where this technique was used.
    • Example Attack Scenario: Explain how an APT group leveraged this technique in an intrusion.

  • 4. Detection Strategies

    • Data Sources (up to 3): Identify key monitoring methods to detect this technique.
    • Example Detection Methods: (e.g., Process monitoring, File creation tracking, Registry modification alerts).
    • Behavioral Indicators: Describe what security teams should look for to identify this technique in use.

  • 5. Mitigation Strategies

    • Defense Mechanisms (up to 2): Suggest methods to prevent or reduce the impact of this technique.
    • Examples: (e.g., Application control, Least privilege enforcement, Multi-factor authentication).
    • Security Best Practices: Provide recommendations organizations should implement to mitigate this attack technique.

Task 3: Research Two APT Threat Groups

Step 1. Select Two Recently-Active APT Groups

Choose two APT groups from MITRE ATT&CK (e.g., APT28, APT41, Lazarus Group), focusing on those that have been active within the past five years. Justify your reasoning for selecting these two APT groups.

Step 2. Analyze APT Groups' Activities

Conduct research using MITRE ATT&CK, and its references to credible cybersecurity reports, and incident analyses to gather the following key details for each group:

  • 1. Key Cyber Campaigns:

    • Identify at least two major cyber campaigns associated with the group.
    • Provide a brief summary of each campaign, including:
      • Timeframe of the attacks.
      • Regions or organizations targeted.
      • Impact (e.g., data theft, system compromise, financial losses).

  • 2. Key Objectives:

    • Explain the group's primary motivations, such as:
      • Espionage (state-sponsored intelligence gathering).
      • Financial gain (ransomware, banking trojans).
      • Disruption/Sabotage (damaging infrastructure, political motives).

  • 3. Key Technical Methods Used:

    • Describe the group's commonly used attack methods, such as:
      • Spear phishing (email-based attack delivery).
      • Zero-day exploits (exploiting unknown software vulnerabilities).
      • Supply chain attacks (compromising third-party software or vendors).

  • 4. Key Security Goals Violated:

    • Identify which elements of the CIA triad were compromised:
      • Confidentiality (e.g., sensitive data theft).
      • Integrity (e.g., data manipulation, wiping).
      • Availability (e.g., DDoS attacks, ransomware).
    • Provide specific examples from past campaigns.

  • 5. Primary Attack Techniques (Three Per Group):

    • Identify three main techniques used by the APT group, referencing MITRE ATT&CK.
    • Include the MITRE ATT&CK Technique ID (e.g., T1566 - Spear Phishing).
    • Explain how the group uses each technique in their attacks.

  • 6. Industries or Organizations Targeted:

    • List the sectors most affected, such as:
      • Government, Defense, Healthcare, Financial Services, Critical Infrastructure, Media.
    • Provide examples of specific organizations or countries targeted in past campaigns.

Task 4: Reflection and Analysis

Write a structured reflection essay (300–350 words) addressing the following sections:

  • 1. Challenges in Detecting APTs (100–125 words)
    Discuss why APTs are difficult to detect, considering:

    • Stealth and Persistence: How do APTs evade detection over extended periods?
    • Advanced Evasion Techniques: How do they bypass traditional security controls?
    • Use of Legitimate Tools: Why do attackers use system tools like PowerShell, WMI, or living-off-the-land binaries (LOLBins)?
    • Slow, Targeted Operations: Why do APTs operate over months or years without raising alarms?

  • 2. Challenges in Defending Against APTs (100–125 words)
    Discuss why APTs are difficult to defend against, considering:

    • Sophistication of Attackers: How do APT actors adapt and evolve their methods?
    • Zero-Day Exploits: Why are undiscovered vulnerabilities a major challenge?
    • Supply Chain Attacks: How do APTs infiltrate through trusted third-party vendors?
    • Human Factor & Social Engineering: Why is phishing and insider threat management crucial?

  • 3. Insights from Researching APTs and MITRE ATT&CK (100–125 words)
    Reflect on what you learned from analyzing APT groups and the MITRE ATT&CK framework:

    • How did studying real-world APT groups change your perspective on cybersecurity?
    • What did you learn about Tactics, Techniques, and Procedures (TTPs)?
    • How does MITRE ATT&CK help organizations understand, detect, and mitigate APT attacks?
    • Were there any surprising discoveries about how APTs operate or how organizations respond?

Tasks for Section 2

Task 1: Cybersecurity Testbed Setup

  1. Follow the testbed setup guide, provided on Canvas Module "Testbed Setup for Assignments". This testbed will be used in future assignments to simulate real-world attack and defense scenarios in a controlled environment.
  2. Take screenshots of your Virtual Machine settings (three screenshots), including allocated CPU, RAM, and storage. Ensure the screenshots display the allocated CPU, RAM, and storage settings in the VM manager.
  3. Log into each VM and take three screenshots, one for each logged-in session. Ensure that the desktop or terminal is visible in each screenshot to confirm successful installation and login.

Task 2: Linux Basics and Network Connectivity

Power on all three VMs and log into each one. With all VMs running in the isolated host-only network, perform the following tasks on one of the Kali VMs and document your results:

Step 1. Check System Information

  • Open a terminal and run the following commands:
    • uname -a → Display system information.
    • uptime → Show system uptime.
    • whoami → Display the current logged-in user.
    • df -h → Show available disk space.
  • Take a screenshot of the terminal output for each command.
  • Provide a brief explanation of the results, including system details, uptime significance, user identity, and disk space usage.

Step 2. View Network Configuration

  • Run the following commands and record the output:
    • ifconfig or ip a → Display network interface details, including MAC and IP addresses.
    • ip route → Show the system's routing table.
  • Take a screenshot of each command's output.
  • Provide a short explanation of the network configuration, including:
    • The assigned IP and MAC addresses and their roles in network communication.
    • Whether the IP address belongs to the expected subnet range assigned in the testbed setup (e.g., 192.168.x.1, such as 192.168.10.1).
      • If the IP is correct, explain how it was assigned and why it aligns with the expected testbed configuration.
      • If the IP does not match the expected subnet, investigate and explain potential misconfigurations and troubleshooting steps taken to resolve the issue.

Step 3. Test Connectivity Between VMs

  • Use ping to verify network communication:
    • From Attacker VM (Kali), ping Metasploitable 2.
    • From Metasploitable 2, ping Defense VM (Kali).
  • Take screenshots of successful ping results to confirm network connectivity.
  • If pings fail, document troubleshooting steps taken to resolve connectivity issues.

Step 4. Network Scanning with Nmap

  • Identify the IPv4 address of the Metasploitable 2 VM using ifconfig or ip a.
  • From the Attacker VM (Kali), perform a port scan on Metasploitable 2:
    • Run nmap -p 1-1024 <Metasploitable2-IP> to scan for open ports in the well-known range (1-1024).
  • Take a screenshot of the Nmap scan output.
  • Highlight five open ports and their associated services in the scan results.
  • Provide a brief analysis explaining potential security risks based on the attack surface concept, discussing how attackers might exploit the exposed ports.

Step 5. Check Running Processes & Active Connections

  • On one of the Kali VMs, run the following commands:
    • ps aux → List all running processes.
    • netstat -tulnp → Display active network connections and listening ports.
  • Take screenshots of the running processes and active network connections.
  • Identify and explain any suspicious or notable processes or network connections, considering their potential security implications.

Step 6. Set Defense VM eth0 to Promiscuous Mode (VirtualBox)

  • 🔧 Set Promiscuous Mode in VirtualBox Interface

    1. Shut down the Defense VM.
    2. Open VirtualBox Manager.
    3. Select the Defense VM → click Settings → Network.
    4. Under Adapter 1, expand Advanced.
    5. Set Promiscuous Mode to Allow VMs.
    6. Click OK to save changes.

  • 💻 Enable Promiscuous Mode in the Guest OS

    1. Start the Defense VM.

    2. Open a terminal and run:

      sudo ip link set eth0 promisc on

    3. (Optional) Verify:

      ip link show eth0

      Look for PROMISC in the output.

  • Take screenshots of the output showing eth0 in PROMISC mode.
